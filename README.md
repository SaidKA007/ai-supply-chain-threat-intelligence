# AI Supply Chain Threat Intelligence

**A student project about security risks in downloaded AI models and the software used with them.**

## What is this about?

Imagine downloading a useful AI model, only for hidden code to run when you load it. This project examines published cases involving malicious model files, altered chat templates, compromised software packages, and reused model-repository names.

The **AI supply chain** is the path through which models, data, and supporting software reach their users. Our goal is to understand how this chain can be abused and how to collect and analyze evidence about these threats.

## Scope and transparency

This is educational research, not a tested detection system. No malicious models were executed and no live targets were scanned for these increments. Published incidents and research demonstrations are kept separate; historical indicators are not assumed to remain malicious today.

Sources and limitations are documented in each weekly report. Generative AI assisted with research support, code, data organization, diagrams, and documentation; it is not the source of factual evidence.
