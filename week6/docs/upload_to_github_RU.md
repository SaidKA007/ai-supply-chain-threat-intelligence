# Как загрузить Week 6 в GitHub

## 1. Распакуй архив

Внутри находится папка `week6`. Перенеси её целиком в корень своего репозитория `ai-supply-chain-threat-intelligence`, рядом с `week4` и `week5`.

Если в репозитории уже лежит старая `week6` с Pickle-симуляцией, сначала сохрани её резервную копию и замени содержимое новой версией. Не смешивай старый README и старые результаты с новым экспериментом CNN.

## 2. Загрузи папку целиком

В GitHub можно использовать **Add file → Upload files**, затем перетащить папку `week6` в корень репозитория. Либо из локальной копии репозитория выполни:

```bash
git add week6
git commit -m "feat(week6): add CIFAR-10 backdoor lab and evidence"
git push
```

Это команды для твоего запуска. Сам репозиторий при подготовке архива не изменялся.

Не загружай только README: картинки, модели, ноутбуки и таблицы нужны по относительным путям. Сам ZIP внутри репозитория хранить необязательно.

## 3. Проверь страницу

Открой `week6/README.md` на GitHub. Должны отображаться картинки датасета, красный X, пример dog/airplane, график и HTTP-скриншот. Ссылки на `week4` и `week5` рассчитаны на расположение этих папок рядом с `week6`.

## Что важно при защите

Основные числа сохранённого запуска: **71,69% / 72,32% / 39,48%**. Старый скриншот с 70,91% находится в архивном подразделе и не используется как baseline итоговой таблицы.

CNN изменила классификацию. HTTP-запрос сделал отдельный Python-компонент. Настоящего reverse shell, генерации текстов и кражи настоящих данных не было.

Оригинальный `.ipynb` сохранён без изменения. Второй ноутбук предназначен для нового запуска по сохранённым весам и не содержит выдуманных результатов.
