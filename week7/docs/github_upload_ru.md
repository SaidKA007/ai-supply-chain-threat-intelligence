# Как добавить Week 7 в GitHub

В архиве находится папка `week7`. Помести её целиком в корень существующего
репозитория `ai-supply-chain-threat-intelligence`, рядом с `week5` и `week6`.
Не переноси только README: изображения и внутренние ссылки зависят от структуры.

Через сайт GitHub: открой репозиторий → Add file → Upload files, перетащи папку
`week7`, проверь пути `week7/README.md`, `week7/images/...` и остальные, затем
сделай commit. ZIP сам по себе не заменяет распакованную папку для отображения README.

Через Git, находясь в локальном корне репозитория:

```bash
git status
git add week7
git commit -m "docs(week7): document CAR-inspired Velociraptor process detection"
git push
```

Просмотри `git status` перед коммитом. Не добавляй приватные конфиги Velociraptor,
его datastore, ключи или необработанные экспорты с личными данными.
В архив включены публикационные версии скриншотов с явно отмеченными скрытыми полями.

Для главного README есть готовый фрагмент `root_readme_snippet.md`.
Он предназначен для вставки вручную; главный README репозитория не изменялся.

Это готовый отчёт о выполненной endpoint-практике. В нём не заявляется, что
Velociraptor является SIEM или что преподаватель уже согласовал такую замену.
