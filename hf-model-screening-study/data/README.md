# Data status

No live dataset is included in the starter. The collector creates a new timestamped subdirectory after you run it. Retain `selection.json`, `metadata.jsonl`, `run.json`, `errors.json` and `pilot.md` together.

The metadata inventory is unlabelled with respect to backdoors. It is NOT a collection of clean controls and does not provide model-level ground truth. The controlled experimental benchmark is a separate future milestone described in the protocol.
